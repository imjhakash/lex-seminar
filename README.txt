HOW TO USE
- Open index.html in any browser (works offline, no server needed).
- Click "Open Brochure" -> music starts. Speaker button turns music on/off.
- Arrows / keyboard left-right / swipe on phone to change pages.

CHANGE THINGS
- Music: replace assets/music.mp3 (keep the same name).
- PDF pages: put new page images in pages/ and list them at the top of script.js.
- Download button uses assets/brochure.pdf.
